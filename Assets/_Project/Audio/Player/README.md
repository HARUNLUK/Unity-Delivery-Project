# 🚶 Player Audio Files (Karakter Sesleri)

Bu klasöre aşağıdaki isimlerle ses dosyalarınızı (`.wav`, `.mp3` veya `.ogg`) ekleyebilirsiniz:

- `Player_Footstep` : Temel adım sesi (Kod içerisinden zemin/koşu hızına göre pitch ve hız otomatik modüle edilir)
- `Player_Jump` : Zıplama sesi
- `Player_Land` : Yere iniş sesi
