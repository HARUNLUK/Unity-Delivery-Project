# Cargo Audio Files (Kargo & Fizik Sesleri)

Bu klasöre aşağıdaki isimlerle ses dosyalarınızı (`.wav`, `.mp3` veya `.ogg`) ekleyebilirsiniz:

- `Cargo_Grab` : Koliyi yerden/kasadan kavrama karton sesi
- `Cargo_Drop_Light` : Koliyi yavaşça yere koyma sesi
- `Cargo_Drop_Medium` : Kolinin orta şiddette çarpma / düşme sesi
- `Cargo_Drop_Heavy` : Kolinin sert çarpma sesi
- `Cargo_Throw` : Koliyi ileri fırlatma hava sesi (Whoosh)
- `Cargo_Fragile_Rattle` : Kırılabilir koli sallanma / cam çıngırtı sesi
- `Cargo_Fragile_Break` : Kırılabilir koli kırılma / cam patlama sesi
- `Cargo_Explosive_Beep_Warning` : Patlayıcı koli hasar aldıkça hızlanan bip uyarısı
- `Cargo_Explosive_Detonation` : Patlayıcı koli patlama sesi
