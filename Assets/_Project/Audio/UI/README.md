# 🖥️ UI Audio Files (Arayüz & Sistem Sesleri)

Bu klasöre aşağıdaki isimlerle ses dosyalarınızı (`.wav`, `.mp3` veya `.ogg`) ekleyebilirsiniz:

- `UI_Tablet_Open` : Kargo tableti açılış sesi (Aynı zamanda Gün Sonu Bilançosu açılışında da kullanılır)
- `UI_Tablet_Close` : Tablet kapanış sesi
- `UI_Tab_Switch` : Sekme değiştirme sesi
- `UI_Button_Click` : Buton tıklama klik sesi
- `UI_Notification_Popup` : HUD bildirim açılış sesi
- `UI_Error_Buzzer` : Yetersiz para / hata buzzer'ı
- `UI_Money_Add` : Kasaya para eklenme şıkırtısı
- `UI_Money_Subtract` : Harcama / ceza sesi
- `UI_Level_Up` : Seviye atlama kutlama müziği
